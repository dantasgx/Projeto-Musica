# Projeto-Musica

## Introdução
Durante a aula de Digital Experience Ultimate nos foi apresentado como projeto a ideia de criar um reprodutor de músicas, este deveria reproduzir 5 músicas diferentes, possuindo 4 botões (stop,voltar,play/pause,avançar). Tinhamos portanto o objetivo de montar o reprodutor na plataforma tinkercad e posteriormente monta-lo fisicamente no dia da entrega.

## Metodologia
### Materiais
Para este projeto precisariamos de: 1 Arduino Uno, 2 LEDs (um verde e um vermelho), 4 push bottom, 4 resistores (um de 223 Ω, um de 1000 Ω), 1 potênciometro, 1 buzzer e 1 display LCD 16x2.
